# SARPECH Brand Kit (Edition 01)

Start with **SARPECH_Brand_Guidelines.pdf**: the full rulebook (meaning, story, values, voice, logo rules, colours, fonts, patterns, naming, taglines, launch checklist).

| Folder | What's inside | Use for |
|---|---|---|
| logo/ | Primary logo, horizontal lockup, gold/green/white emblems (SVG + PNG), favicon | Everything. SVG for print and embroidery, PNG for web and social. |
| stationery/ | Business card front/back, A4 letterhead (PDF), email signature (HTML) | Printer (90×55 mm card), Gmail signature |
| packaging/ | Hang tag front/back, woven neck label, care label, shopping bag, gift box lid, thank-you card, wax seal sticker | Send to label, tag and packaging vendors |
| social/ | Profile picture, launch post, quote post, product post template, story template, highlight covers, YouTube/Facebook cover | Instagram and other social accounts |
| patterns/ | Zari border, jaali lattice, filigree corner (SVG) + preview | Website, packaging, garment embroidery |
| website/ | PROMPT.md + logo files | Open in Claude Code: "Read PROMPT.md and build the website" |

**Colours:** White #FFFFFF · Sarpech Green #0E1A15 · Zari Gold #C9A04A · Antique Gold #8E6A22 · Ivory #F5EEE0 · Ruby #A3162B
**Fonts (free, Google Fonts):** Cinzel (headings) · Cormorant Garamond (body) · Tiro Devanagari Hindi

Replace placeholders (Your Name, phone, address, GSTIN, prices, barcode) before printing.
For printing, send vendors the SVG/PDF files and ask for a proof. Use metallic gold foil for premium items.
